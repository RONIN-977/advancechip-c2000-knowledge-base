# 当前唯一上位机源码

按照用户要求，本目录为后续唯一维护入口。不要在单个 MCU 工程内复制一份上位机源码。本次合并新增 AVP32F00157，保留当前 UI 优化和所有原有型号。

新增位置：host/Updater.Core/Firmware.cs 的 profile；MainWindow.xaml / .xaml.cs 的选型；tests/Updater.Tests/F2800157Tests.cs 和 F2800157NativeTests.cs 的回归。App.xaml.cs 支持 --self-check-2800157。

构建：pwsh -File scripts/build-host.ps1。
发布：pwsh -File scripts/publish-customer-runtime.ps1 -OutputDirectory '../上位机本低部署版'。
通常只更新现有运行目录；用户要求外发版本时，运行 scripts/package-customer.py 打包该运行目录，不复制或打包源码工程。

00157 专项回归由 UDS_OriCode/AVP32F00157/tests/run.ps1 驱动，自动引用本目录并传入固件目录。测试命令也可使用 --f2800157 <源码目录> <hex2000.exe> <native-model.dll> <固件output目录>。

当前 UI 点击“开始升级”会自动请求 APP 返回 BOOT，完成下载后请求启动，不存在单独的“进入升级”按钮。“读取设备信息”只查询，不自动切换 APP。软件回归和 UI 模拟不代替实板验证。原有源码包说明、历史记录中的路径和型号说明不作为本次新增型号的操作入口。
