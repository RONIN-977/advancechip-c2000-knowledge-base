335 SCI 固件升级工具 — 2026-10-10

完整解压后双击“335 SCI升级上位机.exe”，不要在压缩包内运行。
支持 Windows 10/11 x64，已包含 .NET 运行依赖，无需安装 .NET 或 CCS。
请保留 bridge、drivers、tools、licenses 等配套文件。

1. 提前连接串口适配器，选择正确的串口；界面固定 AVP32F335 / SCI / 115200。
   使用 SCI-A，GPIO28/RX、GPIO29/TX，8N1、共地，并确认适配器电平匹配。
2. 确认 APP 起始地址，点击“选择升级文件”，加载对应的 APP .out。
   不要选择 BOOT 固件。地址须与板内 BOOT 写入基址和 APP 链接入口一致。
3. 点击“开始升级”，再在 9 秒等待期间给板子上电或复位。
   工具约每 50ms 查询版本，只接受有效 BOOT 应答；APP 应答会继续等待。
   本版本不请求 APP 返回 BOOT。9 秒内没有连上，请重新点击开始升级并上电或复位。
4. 握手成功后执行原有擦除、写入、回读和整包 MD5 校验。
   请保持供电和连接，等待“升级完成，启动请求已确认”，然后观察 APP 运行状态。
   升级成功后自动请求 BOOT 启动 APP，无需另外点击重启。
5. 若停止或中断升级，等待设备当前 Flash 操作结束，再从头升级。
   可使用“保存日志”保留问题记录。

配套要求：335 BOOT V201 / 448 KB。工具保留旧版 BOOT 版本检查，
不发送 APP 地址查询，也不通过 BOOT 校验输入地址；地址一致性由配套工程保证。
初次空白芯片仍需先通过调试器下载 BOOT。BOOT 和 APP 固件未修改。

Windows 调度和 USB 串口存在延迟，50ms 为软件发送间隔目标，不是硬实时保证。
本版已完成软件模型和界面验证，实板反复上电升级仍需在实际设备上复测。
