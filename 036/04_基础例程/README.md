# 036 基础例程

[ADP32F036_Example_20241029](<ADP32F036_Example_20241029>) 保留 18 类外设示例，是主要查询入口。[历史差异例程](<历史差异例程>) 仅保留与该完整包源码不同的 8 类；9 个非 Debug 源码哈希完全相同的旧副本已经删除。[补充例程](<补充例程>) 与 [独立 ADC 工程](<独立ADC工程>) 保留独立来源。

例程展示 ADC、eCAN、LIN、OPA、PGA、PWM、SCI、SPI 等寄存器用法。CANFD 示例只作学习，**036 CANFD 当前不推荐客户使用**。旧工程的晶振、Flash 等待、时钟、引脚及外围电路配置不能直接当作量产模板。
