2. Flash 及 Flash API
ADP32F035B 基于国内流片厂商主流的制程工艺设计，FLASH IP 与 F2803x
完全不同，但 FLASH 分区及寻址与 F28035 保持一致，地址段分配如下：
地址范围 程序与数据空间
0x3E 8000 to 0x3E 9FFF Sector H (8K × 16)
0x3E A000 to 0x3E BFFF Sector G (8K × 16)
0x3E C000 to 0x3E DFFF Sector F (8K × 16)
0x3E E000 to 0x3E FFFF Sector E (8K × 16)
0x3F 0000 to 0x3F 1FFF Sector D (8K × 16)
0x3F 2000 to 0x3F 3FFF Sector C (8K × 16)
0x3F 4000 to 0x3F 5FFF Sector B (8K × 16)
0x3F 6000 to 0x3F 7F7F Sector A (8K × 16)
0x3F 7F80 to 0x3F 7FF5 Program to 0x0000 when using the
Code Security Module
0x3F 7FF6 to 0x3F 7FF7 Boot-to-Flash Entry Point (program
branch instruction here)
0x3F 7FF8 to 0x3F 7FFF Security Password (128-Bit) (Do not
program to all zeros)
与 F2803x 类似，在对片上 FLASH 区域进行擦除、编程及校验操作时，工程
中需要调用 FLASH API 接口文件。
一般情况下，用户采用的是芯片内部 BOOT-ROM 区域的 FLASH API，即工程
含有 2803x_FlashAPI_BootROMSymbols.lib 编译，ADP32F035B 在 BOOT-ROM 相同
的地址集成了对其片上 FLASH 进行操作的 FLASH API，用户不需要替换。

=== PDF页 3 ===
如 果 采 用 的 非 BOOT-ROM 区 域 的 FLASH API ， 即 工 程 中 含 有
Flash2803x_API_V100.lib 编译，在移植工程时需要将此文件替换。
如果用户采用的 F28031、F28032、F28033 等型号，这些型号 FLASH 一个扇
区空间大小为 4K*16bit，而工程移植到 ADP32F035B 上，需要按照 ADP32F035B
扇区重新调整 CMD 文件及对 FLASH 操作的扇区地址范围。
Uint16 Flash_Erase(Uint16 SectorMask, FLASH_ST *FEraseStat);
3. 芯片供电及上、下电时序
与 F28035 类似，ADP32F035B 同样支持板级 3.3V 单电源供电方式。设计上
为了做到供电方式兼容，ADP32F035B 增加一级 1.8V 转 1.2V 的线性 LDO，该 LDO
系统内部默认配置输出电压，用户不需要对 LDO 进行程序配置。
器件的上、下电时序由芯片内部匹配，与原 F2803x 产品设计保持兼容，用
户不需要做其它调整。
4. 晶振及运行主频
ADP32F035B 内部集成片上 OSC，分别为 OSC1、OSC2，逻辑上与 F2803x 一致；
ADP32F035B 与 ADP32F035A 不同，内部 OSC 已经修调可以正常使用。
注意：目前送样批次还未进行三温修调，只在常温使用，后续量产批次批
次会进行三温修调。
5. Flash 配置参数

6. ADC 模数转换器
ADP32F035B 器件 ADC 最大时钟频率为 60Mhz，当芯片的工作频率大于 60Mhz
的场景请对 ADC 时钟进行 2 分频。

=== PDF页 4 ===
ADP32F035B 器件通过对寄存器 ADCCTL2.CLKDIV2EN 位置 1 进行 ADC 时钟 2
分频。注意此寄存器受 EALLOW 保护。
7. 随机存取存储器（RAM）
ADP32F035B 器件相较于 F2803x 新增 8K x 16 字的 L4 RAM 区，地址范围为
0x00 A000 - 0x00BFFF。

ADP32F035B 器件无法将 GPIO0/GPIO1 配置成输入模式使用，且输入读取
GpioDataRegs 寄存器的值恒为 0。
