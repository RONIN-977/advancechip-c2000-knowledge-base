# AVP32F0039 CAN 10MHz KB 工程

两个独立工程：BOOT_KB 和 APP_KB。CCS 工程名为 F280039C_Bootloader_KB、F280039C_Application_KB。

- 仅 CAN 在线升级：删除应用层 SCI 初始化、收发、重组和接口定义，删除 SCI 外设时钟使能。
- 通用 vendor Driverlib 头文件/库保持厂商版本，其中通用 SCI API 声明不代表应用使用 SCI。
- 外部晶振 10MHz，PLL IMULT=48、REFDIV=1、ODIV=4、SYSDIV=1，CPU 保持120MHz，LSPCLK30MHz。
- CANA RX GPIO30、TX GPIO31，500000 bit/s，节点1，请求0x601/应答0x581，消息对象RX1/TX2，均未改。
- APP 的 LED 初始化函数、调用、变量与翻转代码用 #if 0 屏蔽，源码保留；调试心跳保留。
- 原 BOOT 不含 LED 闪灯逻辑，因此无对应删除或屏蔽改动。
- APP 起点0x090000，结束0x0AF000不包含；元数据0x08F000。两工程各自的 include/app_partition.h 独立保存。
- 保留原版 APP 进入 BOOT 的应答、写标记和复位流程。Timer0毫秒时基、Timer2 Flash超时配置保持原版。

源码来自 AVP32F0039Boot+APP_20261009/AVP32F0039，未修改该原目录，不生成压缩包。
Debug 包含各工程本次编译 OUT/MAP；验证记录保存导入/编译日志和结果。未烧录或实板验证。
先通过 JTAG 下载本次10MHz BOOT，再用统一上位机选择AVP32F0039/CAN/500000/节点1/APP起点0x090000，升级本次APP_KB OUT。
