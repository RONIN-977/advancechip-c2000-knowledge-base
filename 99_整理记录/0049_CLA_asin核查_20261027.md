## 建议复现步骤

1. 先用 CPU1_RAM，CPU 下载匹配的 OUT，停在第一次 CLA_forceTasks 前。
2. Debug 视图显示全部核心，连接 CLA1，向 CLA1 Load Symbols 加载同一 OUT；核对 CLA 运行状态，准备好后再让 CPU 执行软件触发。CPU 单步不会进入另一个执行单元的 CLA C 函数。
3. 已跑入 main 空循环后才设断点，不会自动再触发；须重新运行初始化与测试。
4. 若仍无响应，在第一次触发前后核对 MIER.INT1、MVECT1（与 MAP 的 Cla1Task1 地址一致）、MIFR.INT1、MIRUN.INT1、CLA PC，以及 LS0 所有权/程序配置。MIFR 开始执行会自动清除，MIRUN 正常短任务可能采不到1，单次为0不能证明没执行。
5. 调试停住 CLA 时，CPU 的 WAITSTEP 只等固定周期，并不等待人工调试完成；此时 pass/fail 不作为计算正确性证据。连续运行测试时可在副本暂时屏蔽 mdebugstop，重新构建下载，期望 pass=64、fail=0，再结合结果判断执行情况。
