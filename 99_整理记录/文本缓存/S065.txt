1 概述
湖南进芯电子科技有限公司所发布的 ADP32F03XB 与 ADP32F03X 为两个系列的产品，
但引脚排布相同。基于产品推广与客户需求，需要说明两个系列产品的差异项，该文档旨在
说明 ADP32F03XB 与 ADP32F03X 的差异项。
2 差异项说明
2.1 主频差异性
ADP32F03XB 设计主频是 100MHz，ADP32F03X 设计主频是 60MHz。
2.2 SARAM 存储容量差异
ADP32F03XB 产品 SARAM 容量在 ADP32F03X 产品的基础上新增 L4 SARAM，其容
量大小为 8K x 16 位，地址映射空间位 0xA000--0xC000。其应用及功能特性与 L0、L1、
L2、L3 的应用及功能特性无差异。
2.3 访问 Flash 及 OTP 最小等待状态的差异
由于不同系统时钟频率具有不同的等待状态，ADP32F03XB 产品详见数据手册表 6-47，
ADP32F03X 产品详见数据手册表 6-47。鉴于此，需关注应用软件对此等待状态的配置，此
功能点上 ADP32F03XB 与 ADP32F03X 并不兼容。
2.4 Flash 性能参数差异
两款系列产品在 Flash 及 OTP 性能参数上有差异，ADP32F03XB 产品详见数据手册第
6.13 章节，ADP32F03X 产品详见数据手册第 6.13 章节。烧写 Flash 时默认状态下调用
ROM 内的 Flash API ,若需调用.lib 文件，需更换到支持 ADP32F03XB 的.lib 文件。
ADP32F03XB 与 ADP32F03X 的 Flash API 不兼容。

2.6 LDO 内核供电差异
内核供电 LDO IP 调整，ADP32F03X 产品需要在 TEST2 添加电容，ADP32F03XB 产品
不能在 TEST2 脚添加电容，需保持悬空。
