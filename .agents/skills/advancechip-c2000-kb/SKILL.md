# 进芯 C2000 知识库调用

只要用户提到进芯芯片或具体进芯型号，就主动定位本资料库；无需用户写 `$advancechip-c2000-kb`。若只是顺带提及，按实际问题选读相关资料，不必通读整个资料库。纯 TI 芯片问题且未涉及进芯替代时不使用本技能。

资料库是文件，不是本技能内固化的结论。以当前打开的仓库根目录为入口，根目录应包含 `README.md`、`00_替代与差异知识库` 和本技能；本技能所在目录向上三级即为仓库根目录。仓库可克隆到任意路径，不依赖某台电脑的绝对路径。

换电脑后先克隆私有仓库，再安装 GitHub 官方 CLI `gh`，使用获授权的账号执行 `gh auth login`。在仓库根目录用 PowerShell 执行 `./tools/Restore-LargeMaterials.ps1`，从私有 Release 取齐超限原始包；脚本按清单恢复原路径并核对 SHA256。Release 继承私有仓库访问权限。资料缺失或不可读时，明确说明无法访问当前资料，不凭先前对话记忆声称已核实。恢复原始包和哈希一致仅证明资料同步，不代表工程已编译、烧录或实板验证。个人技能目录中的链接或安装不会随仓库克隆自动迁移；直接使用仓库内本技能，必要时按新环境重新配置技能入口。

## 按问题定位资料

1. 从资料库根目录 `README.md` 和 `00_替代与差异知识库/README.md` 定位；只读取与本次问题有关的型号和程序资料。
2. 型号替代与选型：先查 `01_型号替代总表.md`，再查 `02_差异学习笔记.md`、`03_资料冲突与待核实.md`；如涉及供货/学习状态，再查 `05_学习进度.md` 和 `07_待集中确认问题.md`。
3. 程序问题：按型号读取 `00_替代与差异知识库/08_` 至 `14_程序学习_*.md` 的对应笔记，再进入原工程核对源码、链接文件、原理图、OBJ 日期和数据手册。036 从 `036/README.md`、`036/00_规范与勘误/手工同步清单.md` 开始，再区分低压 Q/A2/A3、裸芯高压 AutoACDrive 和通用 LIN/CAN 升级。
   涉及 036 无感 FOC 调试、参数测量/换算、采样标定、启动状态、故障或 PI 整定时，再读 `00_替代与差异知识库/16_036无感FOC调试手册学习笔记.md` 及其引用的原始 PDF。手册是 A2 低压单电阻旧工程基线，先核对目标板和算法 OBJ；依次确认电机参数、采样标定、保护和命令/状态，再讨论环路。不得跨版本直接套用示例单位、额定电流公式、ADC 通道、中断入口或缺相保护片段。
4. 文档结论有冲突或需要精确数值时，回到最新版芯片手册、移植手册、勘误及目标板原理图。TI 对应型号的通用寄存器可作编程基线；进芯新增功能、器件电气/时序、封装及量产限制须用进芯资料核对。

## 形成答案或实施更改

- 区分用户确认的现行量产规则、进芯最新资料、旧版文档、示例工程和个人推断。旧代码的时钟、Flash 等待、供电、保护、升级分区与错误处理不能默认作为可用模板。
- 输出替代关系时写明具体进芯型号、对应 TI 型号、硬件引脚兼容与软件兼容是否各自成立；不要把“寄存器一致”推断为可直接替板或直接量产。
- 涉及程序应用，先确定目标芯片、封装/板版、工程版本、时钟、编译器、BOOT/APP 组合和关键外围电路。只把在源码和目标板中核实过的配置用于修改；资料不足时列出缺口或向用户询问具体必要信息。
- 回答时给出可追溯的本地文件路径和版本；若只完成静态阅读，明确说明没有 CCS 编译、烧录或实板验证。用户新增资料后更新对应知识库笔记和冲突项，避免新结论只留在对话中。
