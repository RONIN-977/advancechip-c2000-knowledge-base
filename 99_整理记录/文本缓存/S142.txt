段落25: 4.软件差异

段落26: ① AVP035的比较器 2 和比较器 3 的使能内部连接错：

段落27: 问题描述：下图是一个比较器的框图，其中比较器 2 的 CMPDACEN 控制位被连接到比较器3，来控制比较器3的使能；相反，比较器3的CMPDACEN控制比较器2的使能。

段落28: 解决方案： 

段落29: 初始化比较器时，没有以上 BUG 的情况下，应如下代码所示： 

段落30: Comp1Regs.COMPCTL.bit.COMPDACEN = 1; // Power up Comparator 1 locally 

段落31: Comp2Regs.COMPCTL.bit.COMPDACEN = 1; // Power up Comparator 2 locally 

段落32: Comp3Regs.COMPCTL.bit.COMPDACEN = 1; // Power up Comparator 3 locally 

段落33: 实际情况如下解释： 

段落34: Comp1Regs.COMPCTL.bit.COMPDACEN = 1; // Power up Comparator 1 locally 

段落35: Comp2Regs.COMPCTL.bit.COMPDACEN = 1; // Power up Comparator 3 locally 

段落36: Comp3Regs.COMPCTL.bit.COMPDACEN = 1; // Power up Comparator 2 locally 

段落37: Note：应特别注意比较器 2 和比较器 3 不同时使用的情况。

段落38: ② 软件工程.c .h和.lib文件替换

段落39: 因AVP035的内核是AVP069，所以在软件移植中需要将ADP035相关的.c（source文件）.h（include文件）和.lib文件替换为AVP069的.c .h和.lib文件

段落40: ③ .lib文件替换方法：

段落41:  在用户原本的ADP035应用程序中，如有程序代码对 Flash 操作，移植时需替换我司提供AVP069的.lib 文件
