段落7: 测试引脚

段落8: TEST1为芯片内核供电的输出引脚，TEST2为内核供电地，TEST1与TEST2中间的电压为芯片的内核电压，在 F28335 中，芯片内部测试引脚建议悬空。AVP32F335B版本中TEST1和TEST2之间悬空处理。

段落9: FLASH使用概述

段落10: AVP32F335 B所使用的 Flash 为宏力提供，该 Flash 的 Program 和 Erase 注入和释放电荷的时间是通过系统时钟计数来保证。计数值是按照系统 时 钟 50MHz为基准。 

段落11: 每次 Program 和 Erase 都会有回读校验，如果 Program 和 Erase 不通过，会重复 Program 和 Erase。频率过高时，一次 Program 和 Erase 不成功（冲放电荷时间不够），会导致多次 Program 和 Erase，可能会刚好落入中间状态，读出值不稳定（如下图）。如果频率过低，每次 Program 和 Erase 时间太长，可能会导致过 Erase 和过 Program 状态。

段落12: 因此建议使用CCS进行AVP32F335B版本的烧录时，将烧写频率降低至120Mhz。

段落28: 芯片供电及上下电时序

段落29: 与 F28335 类似，AVP32F335B 在芯片封装定义上同样支持双电源供电，即 3.3V 与 1.8 或 1.9V。与 F28335 不同，AVP32F335 内部增加一级 LDO，将外部输入 1.8V 或 1.9V 转换 1.65V供给到内核（其中寄存器地址 0x7016 控制数字内核供电，0x7100 控制模拟内核供电），用户不需要在工程中做补充配置。 

段落30: 器件上电、运行过程，应避免发生VDD1V8电平高于同时刻VDDIO3V3电平0.8V以上；注意VDDIO3V3先于VDD1V8上电，系统初始化阶段，ePWM引脚可能输出短时0.7V电平（us级）。

段落45: （4）ADCREFP 和 ADCREFM 基准电压上电时间差异

段落46: ADCREFP 和 ADCREFM 引脚外接 10µf 电容时，AVP32F335B版本的 ADC 带隙基准稳定的延迟时间最大为 10ms。

段落47: ADCREFP 和 ADCREFM 引脚外接 2.2µf 电容时，TMS320F28335版本的 ADC 带隙基准稳定的延迟时间最大为 5ms。

段落48: （5）外设帧 0（PF0）和 2（PF2）的 ADC 结果位置差异

段落49: F28335 Peripheral Frame 2 (0x7108-0x7117)为左对齐，低四位（bit[3:0]）为 0 值，Peripheral Frame 0 (0x0B00-0x0B0F)为右对齐，高四位（bit[15:12]）为 0 值。AVP32F335B版本与其一致。

段落50: 因此CPU或DMA访问ADC镜像结果寄存器不需要右移4位。

段落58: I/O

段落59: AVP32F335B版本集成 I/O 端口，输出驱动上管 PMOS 与下管 NMOS 采用输出驱动自适应设计，如下图所示，输出控制电路使输出驱动 PMOS 在输出电压上升至约 2.4V 后关闭 MP1，输出驱动 NMOS 在输出电压下降至约 0.4V 后关闭 MN1，因此电平上升及下降时间与 F2833x 存在差异性，对于一般 I/O 驱动应用用户不需要对现有设计调整。

段落60: 复位

段落61: AVP32F335B版本复位电路可兼容F28335的设计，RC电路电阻为2.2kΩ，电容为100nf。

段落62: 总结

段落63: 以上是针对目前大部分用户在从 F28335 向 AVP32F335 B版本移植过程中可能涉及的差异、产生调试问题的总结。用户在进入产品测试前，应在软件及硬件上重点关注芯片晶振型号输入、ADC 基准、Flash 烧写程序及在线程序部分代码与 FLASH API 关联性、FLASH 存储地址分配差异性，以便快速实现工程移植。本文档还总结了AVP32F335的A/B版本之间的差异，可具体结合两个文档来进行参考。
