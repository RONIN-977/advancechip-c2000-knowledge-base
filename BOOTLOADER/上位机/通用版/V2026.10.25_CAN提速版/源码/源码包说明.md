# 当前上位机源码包（2026-10-08）

此包对应当前源码，包含最新 SCI 诊断修改：串口超时日志输出 TX、RX 字节数、有效帧数及接收 HEX。所有现有型号与功能保留，AVP32F035 选择 TMS320F28035。

解压到本地短路径，使用 Windows x64、.NET 10 SDK、PowerShell 7。开发构建还需要 Windows .NET Framework 4.x 编译器（脚本用于生成 x86 CAN 桥接）。

在本目录执行：

```powershell
pwsh -File scripts/build-host.ps1
```

运行生成的 host/Updater.Desktop/bin/Release/net10.0-windows/Updater.Desktop.exe。

发布与当前交付方式一致的自包含运行目录：

```powershell
pwsh -File scripts/publish-customer-runtime.ps1 -OutputDirectory build/customer-runtime
```

首次发布可能需联网取得 .NET 运行时包。产物为 build/customer-runtime/统一升级上位机.exe，分发整个 customer-runtime 目录。

包含解决方案、全部 C# 项目、测试源码、协议文档、构建发布脚本、assets 驱动/工具/许可证及 build/firmware 必需测试样本。排除 bin、obj、开发缓存、重复发布文件及旧日志。assets 中的 EXE/DLL 是驱动安装器、转换工具和运行依赖，故予以保留。

MCU 工程不包含在此上位机源码包内。AVP32F035 BOOT/APP 请使用单独的 AVP32F035_Bootloader_APP.zip；原 README 中旧 F280035_Bootloader 路径已失效。280049/335 专项集成测试和 publish-portable.ps1 需要相应外部固件工程；本包直接构建和 publish-customer-runtime.ps1 无需这些外部工程。F28035 专项测试目前仍使用开发目录中的 AVP32F035/output 相对路径，独立解压后运行专项测试前需调整该测试路径。
