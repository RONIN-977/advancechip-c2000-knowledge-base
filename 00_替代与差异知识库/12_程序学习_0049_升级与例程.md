# AVP32F0049：在线升级与例程

更新时间：2026-09-23。本轮静态阅读 [A024_AVP32F0049_example](<../AVP32F0049/A024_AVP32F0049_example/A024_AVP32F0049_example/examples>) 的升级及代表性外设源码；未重新编译、运行上位机或实板升级。**用户已确认 0049 全批次、全温度及所有客户项目的 CPU 时钟强制不超过 100 MHz，120 MHz 必须规避**。原始例程不能推翻此规则。

Live DFU 的 [核心实现](<../AVP32F0049/A024_AVP32F0049_example/A024_AVP32F0049_example/examples/flash/flashapi_ex2_boot/source/flashapi_ex2_ldfu.c>)接收 SCI Boot 格式镜像（起始 key `0x08AA`），按当前 Bank 编译配置擦写**另一 Bank 的 Sector2–15**、逐段编程和校验；Bank0 的 `0x080000–0x082007`、Bank1 的 `0x090000–0x092007` 被保留给 Kernel/状态。状态字 `START=0x5A5A`、`KEY=0x5B5B5B5B` 与递减的 REV 值写入目标 Bank；启动时 `bankSelect()` 根据 REV 选择 `0x8EFF0` 或 `0x9EFF0` 入口。对应布局见 [Kernel 链接脚本](<../AVP32F0049/A024_AVP32F0049_example/A024_AVP32F0049_example/examples/flash/flashapi_ex2_boot/AVP32F0049_flash_bank0_LDFU_lnk.cmd>)及 [Bank0](<../AVP32F0049/A024_AVP32F0049_example/A024_AVP32F0049_example/examples/flash/flashapi_ex3_live_firmware_update/AVP32F0049_flash_api_liveFirmwareUpdate_bank0_lnk.cmd>)/[Bank1](<../AVP32F0049/A024_AVP32F0049_example/A024_AVP32F0049_example/examples/flash/flashapi_ex3_live_firmware_update/AVP32F0049_flash_api_liveFirmwareUpdate_bank1_lnk.cmd>) APP 链接脚本。**不能把这些地址套用 0039 或 035 的 BOOT/APP。**

SCI 命令外框由源码 `sciGetPacket()` 按 `0x1BE4 + 长度 + 命令 + 数据 + 累加和 + 0xE41B` 解析，正确/错误返回 `ACK=0x2D`/`NAK=0xA5`。Live DFU 命令是 `0x0700`，之后的镜像采用 SCI Boot 格式，不是继续发送普通命令包。资料包未见配套的 0049 专用上位机源码或操作流程，也未找到 0049 的 **CAN/LIN 在线升级 BOOT/APP**；CAN、LIN 目录目前是外设例程，不能据此声称有 CAN/LIN 升级能力。

## 用于项目之前的核对点

1. **100 MHz 为强制边界。**三个升级工程的 `device.h` 以标称 20 MHz 外部时钟、`IMULT=10`、`SYSDIV=2` 配成 100 MHz，Flash API 参数也传 100。接入客户板时，应核对实际晶振/时钟输入、PLL、`DEVICE_SYSCLK_FREQ`、Flash 等待和所有外设分频；不能仅改一个频率常量。
2. `ex2` 的 `sciGetPacket()` 以及 `ex3`/`ex5` 的同名函数都将数据写入 `uint16_t data[10]`，循环次数由收到的长度直接决定，**没有在写数组前约束长度不超过 20 字节**。这属于源码可见的越界风险；投产前需限制长度并测试异常包。校验和只能检测传输错误，不能代替固件签名/真实性校验。
3. `ex2` 的 SCI 初始化调用 `SysCtl_setLowSpeedClock(SYSCTL_LSPCLK_PRESCALE_14)`，随后 `SCI_setConfig()` 却传入按 `DEVICE_SYSCLK_FREQ/4` 定义的 `DEVICE_LSPCLK_FREQ`；自动波特率后能否覆盖这一差异须实测。`ex3`/`ex5` 直接把 SCIA 时钟参数写死为 25 MHz，同样依赖实际 100 MHz、LSPCLK 四分频配置。
4. `ex5` 的无复位切换还涉及中断、RAM 状态和两份 APP 的链接入口；现有工程未定义 `BANK0/BANK1`，因此本轮只能把它视作待补全示例。`ex2` 的 Bank 选择及写入地址、KEY/REV 机制也要和最终产品的断电恢复与回退策略一起实测，不能从示例名称推断已具备安全回滚。
5. 大包中有部分 `device.h` 选择 `SYSCTL_OSCSRC_OSC2`，同时仍把 `DEVICE_OSCSRC_FREQ` 写成 20 MHz、注释称外部 XTAL；这些文件的**时钟源与频率假设不一致**。逐个使用例程前检查有效 `DEVICE_SETCLOCK_CFG`，不能因为注释写“100 MHz”就认定芯片实际只跑 100 MHz。
