# 335 SCI 20261010

本次基线为用户指定的桌面 CHIP/BOOTLOADER/上位机源码.zip，
原压缩包 SHA256：D5D25F5127D98047C7AFE4DE2B120D3C2E63B304E45FADF4314CAB25A037B871。
未采用此前增加 0x76 APP 地址查询的源码。BOOT、APP 及现有通用运行包保持桌面基线内容。

默认构建 Customer335Only=false，保留所有型号与原有通讯流程。
只在 Customer335Only=true 时固定 335 / SCI / 115200，隐藏其他入口和读取、重启按钮。
版本名称与界面使用中性名称“335 SCI 固件升级工具”。

从此目录执行：

```powershell
# 通用版
dotnet build host/Updater.Desktop/Updater.Desktop.csproj -c Release
# 独立 335 SCI 自包含发布
./scripts/publish-customer-runtime.ps1 -Customer335Only -OutputDirectory ./build/335_SCI升级上位机_20261010
# 单独验证新握手，使用真实传输代码和内存 UART
dotnet run --project tests/Updater.Tests -c Release -- --335-handshake
# 原有协议回归
dotnet run --project tests/Updater.Tests -c Release
dotnet run --project tests/Updater.Tests -c Release -- --custom-address
```

构建需 .NET 10 SDK；发布包面向 Windows 10/11 x64，运行时无需安装 .NET。
发布脚本支持 -Dotnet 指定 SDK、-PackageCache 指定缓存，构建不依赖本机绝对路径。
新握手全程 9 秒、约 50ms 重发同一 0x01 请求、初始串口读取等待 5ms；
单调时钟控制，分段报文状态跨重发保留，成功、超时或取消后恢复原 50ms 读取设置。
仅收到有效且匹配的 BOOT 应答才开始原有升级流程；APP 应答继续等待。
保留 BOOT V201 校验，擦写、回读、MD5、三次超时尝试以及完成后的启动请求。
不发送 APP 起始地址查询，不要求新增 BOOT 命令。
输入地址和 OUT 范围校验按旧版保留；BOOT 写入基址与 APP 链接地址由工程配套保证。

软件验证记录及旧文件置于项目库根目录的历史归档，未打入运行 ZIP。
Windows 与 USB 延迟不构成硬实时保证；实板反复上电升级需使用实际板卡复测。
