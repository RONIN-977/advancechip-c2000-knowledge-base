# AVP32F335：Rev2.0 开发板例程学习

更新时间：2026-09-23。资料入口：[Rev2.0](<../AVP32F335/Rev2.0>)，包含开发板用户手册、板图和 `AVP32F335_CCS3.3version Templates_V2.2` 源码。这里的 **Rev2.0 是开发板/资料包版本，不能当成芯片 A/B 版本**。已静态阅读 13 个独立示例入口及关键外设初始化；没有 CCS 编译或实板测量。在线升级的 BOOT/APP 另见 [335 CAN 在线升级](<08_程序学习_335_CAN在线升级.md>)。

## 共用工程框架

13 个工程各自带一套 `AVP33x_` 头文件、外设支持源文件及 CCS3.3 `.pjt`，不能因目录里有 `AVP33x_ECan.c`、`AVP33x_Adc.c` 等支持文件，就认为该示例实际使用了所有外设。入口一般先把 `ramfuncs` 拷至 RAM，设置 Flash 等待，配置 PLL/外设时钟，然后初始化本例需要的 GPIO、PIE 和外设。所有工程的 `AVP33x_Examples.h` 均配置 `DSP28_PLLCR=10`、`DIVSEL=2`、`CPU_RATE=6.667 ns`；配套代码说明采用外部 30 MHz 时，实际 SYSCLKOUT 为 150 MHz。这与 **CAN 在线升级工程设为 PLLCR=4、60 MHz** 不同，两套工程的波特率、定时器和 Flash API 比例不可混用。

## 每个示例的学习结论

| 示例 | 实现与查阅入口 | 主要注意点 |
|---|---|---|
| ADC | [Ex_ADC](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_ADC/src/Ex_ADC.c>)：连续转换 ADCINA2，轮询结果写入 `SampleTable`；`InitAdc()` 从片内地址装载增益/偏置修调并等待参考建立。 | 150 MHz 下 `HISPCP=3`、`ADCCLKPS=1`，按源码分频计算 ADC 时钟为 **12.5 MHz**，符合已确认上限；源码的“15 MHz”注释是另一配置的遗留值。读取 `ADCRESULT0 >> 4`，而当前 B 版 ADC 结果对齐规则需按现行文档和实际寄存器逐项复核，不能只照旧例程处理。 |
| ePWM | [Ex_PWM](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_PWM/src/Ex_PWM.c>)：ePWM1–3 的 GPIO0–5、对称计数、CMPA/B 影子装载、动作限定与中断中动态更新比较值。 | 这是波形/中断演示，未构成电机驱动所需的完整死区、故障关断和 FOC 控制链。调整主频时要重算 TBPRD 与频率。 |
| CAN 自回环 | [Ex_CAN_Back2Back](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_CAN Ex_FJ3461AH/Ex_CAN/Ex_CAN_Back2Back/src/Example_AVP33xCAN_Back2Back.c>)：eCAN 自测试下 MBOX0–15 对应 MBOX16–31，统计通过/错误。 | 只验证模块内部邮箱链路，不验证收发器、终端电阻或物理总线。 |
| CAN 双板收发 | [Ex_CAN_Tx](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_CAN Ex_FJ3461AH/Ex_CAN/Ex_CAN_Tx/src/Example_AVP33xCAN_Tx.c>)、[Ex_CAN_Rx](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_CAN Ex_FJ3461AH/Ex_CAN/Ex_CAN_Rx/src/Example_AVP33xCAN_Rx.c>)：分别用 MBOX0 发送、MBOX16 中断接收；配套 [说明](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_CAN Ex_FJ3461AH/说明.docx>)说明两板连接。 | 支持库实际将 eCAN-A 映射到 GPIO18/RX、GPIO19/TX；与升级工程的引脚一致。自测通过不能代替双板测试。 |
| RS232 | [Ex_RS232](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_RS232/src/Ex_RS232.c>)：SCIA 9600 bit/s，FIFO 轮询收一个字符后回显。 | V2.2 [变更说明](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/说明.txt>)指定改为 GPIO28/RX、GPIO29/TX；实际复用见同工程 `AVP33x_Sci.c`。`Ex_RS232.c` 文件头的旧 GPIO14/15 注释不能作为接线依据。这是回显示例，不是串口升级。 |
| RS485 | [Ex_RS485](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_RS485/src/Ex_RS485.c>)：SCIC 9600 bit/s，GPIO62/RX、63/TX，GPIO49 控制收发器方向，同样做字符回显。 | `scic_xmit()` 写入 `SCITXBUF` 后立即把 GPIO49 切回接收，未等待移位寄存器完成；在方向受控的 485 收发器上可能截断发送，复用前要修正并实测。不是 RS485 在线升级。 |
| I²C EEPROM | [Ex_I2CEeprom](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_I2CEeprom/src/Ex_I2CEeprom.c>)：I2C 从地址 `0x50`，向偏移 `0x0030` 写 4 字节，再用重复起始流程读回并比较。 | 对象是**板上外部 I²C EEPROM**，不是芯片内建 EEPROM；读操作处理 EEPROM 写忙的 NACK 重试。 |
| DMA/XINTF | [Ex_Dma_Xintf](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_Dma_Xintf/src/Ex_Dma_Xintf.c>)：Timer0 触发 DMA 通道 1，将 XINTF Zone7 的外部 SRAM 数据搬至片内 L4 RAM。 | 配置的是 32 位 DMA，源/目标地址步进为 2；依赖开发板外部 SRAM。335 的 XINTF 冷启动访问勘误仍应单独核查，例程运行不能证明所有上电条件都安全。 |
| SPI/McBSP 音频 | [Ex_TLV320AIC23](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_TLV320AIC23/src/Ex_TLV320AIC23.c>)：SPI 配置音频芯片，McBSP-A 用发送/接收中断传输音频数据。 | 依赖特定外部编解码器和板级连线，不是单芯片外设通用自检。 |
| 板上 GPIO/定时器 | [Ex_Beep](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_Beep/src/Ex_Beep.c>) 由 Timer0 中断翻转 GPIO17；[Ex_Switch2LED](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_Switch2LED/src/Ex_Switch2LED.c>) 轮询 GPIO60/61/12/13 并控制 GPIO27/26/25/24。 | 管脚对应 Rev2.0 板上器件，移植到客户板时先核对原理图。 |
| 数码管 | [Ex_FJ3461AH](<../AVP32F335/Rev2.0/AVP32F335_CCS3.3version Templates_V2.2/Ex_CAN Ex_FJ3461AH/Ex_FJ3461AH/src/Example_FJ3461AH.c>)：Timer0 计时并通过 AIP650 驱动显示 9999 递减。 | V2.2 将 AIP650 的 CLK 改为 GPIO35；`AIP650.h` 实际也如此配置，接线应按当前版本。 |

## 与现行 335B 使用规则衔接

- 这些示例主要源于 2019 年前后的 CCS3.3 模板。示例中的片内修调地址、ADC LDO、结果对齐、Flash API 库、等待值及 TEST/PLL 处理，不能越过当前 B 版手册和 [差异学习笔记](<02_差异学习笔记.md>)直接照搬。尤其 ADC 结果对齐应区分具体结果寄存器/镜像寄存器，并按 B 版资料和实测确认。
- 与升级工程比较，Rev2.0 示例的 150 MHz 时钟配置更一致：外部 30 MHz、PLL ×10/2、`CPU_RATE=6.667 ns`，Flash 等待设置为 `5/5/8`。升级工程则配置 60 MHz，但部分注释和宏仍写 150 MHz；参考代码时先确定所选工程的**实际运行频率**。
- 原始例程保持不变。本笔记是代码导航与可用性判断，不表示 13 个例程已在当前出货 B 版芯片上逐项跑通。
