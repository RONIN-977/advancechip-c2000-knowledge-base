# 寄存器资料覆盖清单

资料包版本：1.0.0；整理日期：2026-10-22。适用于本工具首版的离线查询。

## 实际覆盖与完成边界

- 共 4330 条寄存器实例、25919 个字段（含保留位和重复外设实例），覆盖四型号的11类常用外设。实例数量不等于不同寄存器类型数量。
- 19470 个字段建立了TI官方TRM字段表及PDF页定位；13376 个字段从字段表抽取了访问属性与复位值。
- 635 个关键字段实例已另行逐项核对中文用途、编码和访问说明，主要为CAN位时序、PWM时基、SCI/SPI基本控制、ADC常用控制、看门狗和定时器。
- 其余中文解释为TI头文件注释与TRM字段表的术语整理；Values明确标注“TRM术语译注（未逐句人工复核）”，Notes保留英文原文和PDF页。不能据此声称所有字段已完整翻译或人工核对。
- 旧系列035/335的TRM经常仅在图中给访问与复位属性，字段表未列出。本版没有用图文位置猜测属性；未提取项显示“待核对TRM”。
- 所有保留位均明确标记；不统一假定可写0。写一清零、喂狗校验等关键行为在人工核对字段中说明；其他条目须查看原文。
- 未将TI手册的字段覆盖等同于进芯量产或实板验证。尚无本工具生成配置的实板验证。

## 来源与地址规则

- 统一头文件基线：Texas Instruments C2000Ware 6.00.01.00。原文件含TI版权和许可声明，随包保存在docs/sources/f2803x、f2833x、f28003x、f28004x。
- docs/sources/manifest.json记录全部所用头文件、CMD、全局实例定义、官方PDF及提取文本的SHA256。
- TI官方手册：SPRUI10A（2022-06，F2803x）、SPRUI07（2020-03，F2833x）、SPRUIW9C（2024-03，F28003x）、SPRUI33H（2024-06，F28004x）。原始PDF随包离线提供。URL：https://www.ti.com/lit/pdf/sprui10、sprui07、spruiw9、sprui33。
- 字段页号为PDF物理页（从1开始），并保留文档编号。原始字段表提取缓存为对应.pages.json；它是辅助检索文本，原PDF为最终证据。
- 地址是C28x 16位字地址。常规结构由官方CMD基址与类型布局抽取；0039/0049 DCAN有byte_peripheral特殊布局，地址直接采用同版本hw_can.h的CAN_O_*官方偏移。CAN_BTR字地址为CANA_BASE+0xC，不是+0x6。
- F28335 ADCRESULT普通寄存器0x7108–0x7117为12位左对齐，换算前右移4；镜像0x0B00–0x0B0F为12位右对齐，无需右移。见SPRUI07 PDF第490页。
- 首版寄存器资料以各TI系列官方头文件为基线。型号具体封装上是否引出某GPIO、该器件是否实现某外设实例，还应以对应器件数据手册资源表为准；不把系列全集宣称为每个封装全部具备。

## 重建与验证

- 执行scripts/build-register-data.py生成Data/registers.json。若本机有C2000Ware_6_00_01_00则拷入固定版本源文件；否则直接使用随包docs/sources中的源文件重建，不依赖原电脑绝对路径。
- 生成器检查字段位范围和重叠；主代理独立scripts/verify-data.py检查型号/外设覆盖、唯一性、地址锚点和来源哈希。
- 字段表提取采用名称、位起点、位宽同时匹配；未可靠匹配的属性保留缺失，不跨寄存器猜测。
- PDF表格换页、组合字段和旧式图内复位属性存在未提取项；这些属于后续资料完善工作。
