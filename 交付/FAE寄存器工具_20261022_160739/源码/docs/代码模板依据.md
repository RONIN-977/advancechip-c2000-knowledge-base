# 计算与代码模板依据

版本：2026-10-22。模板以 TI 基线核对，显示进芯型号不表示已经完成进芯实板验证。

## 固定接口版本与编译范围

代码模板核对与编译使用 C2000Ware **6.00.01.00** 的 `device_support/f2803x`、`f2833x`、`f28003x`、`f28004x` 以及 `driverlib/f28003x/driverlib`、`driverlib/f28004x/driverlib`。编译器为 TI C2000 CGT **22.6.1.LTS**，EABI，0039/0049/335 使用 FPU32。编译脚本允许显式指定本机安装路径，不会修改客户工程。

运行 Fae.Tests 会实际调用当前 C# 生成器，把计算结果导出为 `artifacts/ccs/*.c`。`scripts/verify-ccs.ps1` 编译这些文件，输出含源文件 SHA256 的 `compile-results.json`。这证明生成片段与固定版本的头文件/API能编译，不证明链接、烧录、总线时序或实板行为。DriverLib库在客户工程中仍需正确链接。

## CAN

- 035/335 是 eCAN：模块时钟为 SYSCLK/2。参照本项目 `docs/sources/sprui10.pdf`（F2803x）和 `sprui07.pdf`（F2833x），CANBTC章节。F2833x原PDF第812–813页明确：物理分频 BRP=BRPREG+1，BRP=1模式不符合ISO11898，不能使用；BRP>=2；TSEG2>=IPT=2 TQ，TSEG1>=TSEG2；SJW<=min(4,TSEG2)。输出SAM=0单次采样，保留位写0。
- 0039/0049 是DCAN：时钟可来自SYSCLK或外部晶振，须与客户工程时钟源选择一致。参照官方TRM及对应 `can.h/c` 的 `CAN_setBitTiming()`。参数是**编码值**：BRP=(物理分频−1)&63，BRPE=(物理分频−1)>>6，TSEG1/2和SJW均减1；总分频范围1～1024。
- 公式：`bitrate=CANCLK/[BRP×(1+TSEG1+TSEG2)]`；采样点为`(1+TSEG1)/(1+TSEG1+TSEG2)`。候选范围为8～25 TQ，TSEG1=2～16，TSEG2=1～8（eCAN最低2），SJW=1～4，满足相应限制。
- 按波特率误差绝对值、距目标采样点的差值、较大总TQ依次排序。相同时间段只需测试理想分频相邻整数；不会丢失该时间段的最优整数分频方案。默认采样点80%、SJW1，不能替代结合总线长度、收发器延迟和晶振误差的工程核算。
- eCAN使用32位shadow读写CANMC/CANBTC；请求CCR，等待CCE，再写时序并恢复原CCR。等待硬件应答的循环不带板级超时策略，客户应按自身故障处理要求接入。DCAN位域版本保留原CAN_CTL状态并清CCE；DriverLib使用原库配置进入/恢复逻辑。
- 不生成GPIO、外设时钟使能、邮箱或中断代码，不更改PLL或CAN时钟源。
- 035/335额外核对所填外部晶振到主频的PLL倍频/分频可达关系（SPRUI10A第67/69页、SPRUI07第67/72页）；例如335的10 MHz不能按TI基线PLL得到150 MHz，默认采用30 MHz。此项不代替振荡器电气范围、VCO规格与锁定状态检查。0039/0049只核对主频范围及所选CAN时钟来源，未输入完整PLL参数，不声称已验证其PLL配置。

## PWM

依据对应型号TRM的ePWM Time-Base章节，以及官方 `epwm.h` 的分频枚举和 `EPWM_setClockPrescaler`、`EPWM_setTimeBasePeriod`、`EPWM_setTimeBaseCounterMode`。

`TBCLK=SYSCLK/EPWMCLK外设分频/HSPCLKDIV/CLKDIV`。HSP分频允许1/2/4/6/8/10/12/14；CLK分频允许1/2/4/8/16/32/64/128。旧型号EPWMCLK=SYSCLK；0039/0049可选择1或2，必须匹配工程系统配置。主频上限采用本版所选TI型号基线：035为60 MHz、335为150 MHz、0039为120 MHz、0049为100 MHz。

向上/向下计数：`f=TBCLK/(TBPRD+1)`；上下计数：`f=TBCLK/(2×TBPRD)`。周期为16位，双向计数禁止TBPRD=0。四舍五入得到周期并报告实际频率与误差。仅生成时基参数，须在初始化/时基停止阶段调用。

## ADC、地址与程序员计算器

- ADC是12位单端理想换算：`Vpin=code×Vref/4096`。电压反算按最近码估计并将Vref端点饱和到4095，不模拟ADC转换噪声和器件误差。`Vin=Vpin×分压倍率`；`I=(Vpin−零点偏置)/(放大倍数×采样电阻)`。四个型号的模拟前端实际参考电压必须按板卡填写。
- 地址使用任意精度整数计算，结果限定32位地址空间；区间包含首尾。字寻址的每个地址单元是16位即2字节。容量反算输入单位始终为字节；字寻址拒绝奇数字节容量。1KB=1024字节，1Kword=1024个16位字。
- 程序员模式每一步运算按8/16/32/64位截断；HEX/OCT/BIN显示二补码，DEC可切有符号解释。有符号除法向0截断；右移按有符号/无符号选择补符号/补0；移位量>=位宽时清零（有符号负数右移全1）。支持括号及C风格整数运算优先级，不执行任意代码。
