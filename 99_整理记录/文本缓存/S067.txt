1、 简介
目前，在电机控制和电源领域使用微控制器实现数字化控制成为一种趋势，使用微控制器集成模
拟比较器可以实现系统的异常保护，同时也可以减少板级所需的外部模拟组件的数量。本文档主要介
绍 ADP32F03x 系列芯片中的比较器子模块、相关配置说明、以及针对峰值电流控制模式的基本原理
介绍、实现斜率补偿功能、及芯片比较器单元的底层配置。
Advancechip 生产各种 DSP 以实现对工控产品(伺服、变频、电源、电机等)的高效、稳定控制，
并且提供必要工具集的参考设计。这将加快新产品的学习速度并缩短新产品的开发周期。
2、 比较器
ADP32F03x 系列芯片集成了 3 个内部比较器，分别为 Comp1、Comp2 、Comp3，其中比较
器模块类型为 Type 0。
2.1 概述
比较器模块是一个真正的模拟电压比较器，由芯片模拟电源 VDDA 供电。其中核心模拟电路由
比较器、比较器的输入、比较器的输出、内部 DAC 基准。支持的数字电路包括 DAC 控制、与其他片
上逻辑的接口、输出限制模块和可编程控制信号。
2.2 特性
 比较器模块可以监控两个外部模拟输入，或者监控一个外部模拟输入和内部的 DAC 基准值。比
较器的输出可以异步传递，或在符合条件的情况下同步到系统时钟周期。比较器的输出也可以被映射
到 ePWM 中的 TZ 子模块，或者 GPIO 复用输出口。

3、 异常保护
3.1 原理
当设备出现过流、过压等异常事件时，通过 ADC 通道的采集接入内部比较器的一端，另外一端
由内部 10 位的 DAC 设置故障保护基准点，当 ADC 采集到的值大于设置的基准点 COMPSTS 寄存器
的 COMPSTS 位置 1。将比较器的输出映射到 ePWM 中的 TZ 子模块，从而实现 CBC（逐波限流）功
能、One-Shot（单次触发）功能。
3.2 实现流程
关于比较器寄存器的配置如下所示：
 使能时钟：SysCtrlRegs.PCLKCR3.bit.COMP1ENCLK = 1; 
 使能比较器：(*Comp[n]).COMPCTL.bit.COMPDACEN = 1;
 链接到内部 DAC：(*Comp[n]).COMPCTL.bit.COMPSOURCE = 0;
 选择 DACVAL 基准：(*Comp[n]).DACCTL.bit.DACSOURCE = 0;
 设置 DAC 值：(*Comp[n]).DACVAL.bit.DACVAL = DACval; //Q10
 比较器输出不反向：(*Comp[n]).COMPCTL.bit.CMPINV = 0;
 使能比较器迟滞：AdcRegs.COMPHYSTCTL.bit.COMP1_HYST_DISABLE = 0x1;

4、 峰值电流模式
4.1 PWM 占空比
峰值电流模式是电源控制中的一种控制模式，ADP32F03x 系列芯片具有嵌入式内部比较器，可
以连接到其片上 ePWM 模块，芯片具有斜坡补偿功能，可以实现峰值电流模式不需要额外的组件。
即通过使用器件上的内部数模转换器 (DAC) 为电压提供内部参考。 该内部 DAC 功能在峰值电流
模式控制等数字功率级应用中非常重要，因为该 DAC 可作为峰值电流模式跳闸点的斜坡发生器。 比
较器块的输出也可通过连接至 PWM 跳闸区域而被器件内部使用。
在电压控制模式或平均电流模式下，DSP 计算占空比给到 PWM 模块，但在峰值电流模式控制下，
PWM 跳闸结果产生占空比。
在峰值电流模式的每个 PWM 周期开始时，PWM 打开，电感电流增加。当电感电流增加到参考
电流时，就产生参考电感电流。通常由模拟比较器完成的 PWM 跳闸，然后产生 PWM 占空比。为了
调节占空比，必须计算参考电流。
4.2 斜率补偿
在控制中为了更好的系统稳定性，当占空比超过 50%的时候必须使用斜率补偿，来提高系统的抗
噪声干扰及负载扰动。下图是没有斜率补偿的系统。

4.5 DACVAL 更新
 在控制中电压环的输出作为电流 Iref 基准 Q24，通过 CompValue_Update 函数对 DACVAL 和
RAMPMAXREF_SHDW 的值进行更新。相关函数如下： 
void CompValue_Update(int16 n,int32 compvalue)
{
 EALLOW;
 //Q16 Maximum RAMPMAXREF = 0xFFFF
 (*Comp[n]).RAMPMAXREF_SHDW = (compvalue >> 8); 
 //Q10 to be written to DACVAL
(*Comp[n]).DACVAL.bit.DACVAL = (compvalue >> 14); 
 EDIS;
}
