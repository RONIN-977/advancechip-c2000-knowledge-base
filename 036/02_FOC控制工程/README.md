# 036 FOC 工程入口

调试流程参见 [无感 FOC 手册](<../进芯电子无感FOC调试手册V1.0.pdf>) 和 [学习笔记](<../../00_替代与差异知识库/16_036无感FOC调试手册学习笔记.md>)。先测电机参数、标定采样、核对保护和启动状态，再调 PI；手册的 A2 单电阻参数与代码截图须按目标工程复核。

- [低压 Q/A2/A3](<低压_Q_A2_A3>)：优先看 `ADM32F036A3DEMO_20260720`；其 `Motor/obj` 包含 `SVC_v1.03_20260706_v18_1_4.obj`、`MCQprOL_20260721.obj`、`PWM_20260721.obj`。`260109`、`IPD` 和 `old` 是历史版本；`HallFOC` 是不同位置获取方案，应保留区别。用户确认 A3DEMO 可按板级配置适配 Q、A2、A3，并非仅 A3。核对母线、采样、保护、引脚及预驱电路。
- [高压 ADP32F036 裸芯](<高压_ADP32F036>)：`AutoACDrive` 及 400V 变体是高压程序。两者的封装算法和参数文件仍需按目标压缩机、逆变板区分；不能套用低压 A3DEMO 参数。

这里没有已确认的 A4/A5 FOC 工程。原 `A4_CAN` 包移至 [待核实旧工程](<../06_待核实旧工程>)，内部工程仍叫 A3DEMO、配置宏为 A2。**全部保留工程尚未整体同步最新版修改指南**；应用前先看 [手工同步清单](<../00_规范与勘误/手工同步清单.md>)。
