# 036 程序应用前手工同步清单

依据进芯 [ADM/ADP32F036 系列 BOOT/APP 程序核查与修改指南 V1.1](<036系列 BOOT_APP 程序核查与修改指南和设计应用指南更新/ADMADP32F036系列 BOOTAPP 程序核查与修改指南V1.1.pdf>)、[设计应用指南 V1.5](<036系列 BOOT_APP 程序核查与修改指南和设计应用指南更新/进芯ADM和ADP32F036系列设计应用指南-V1.5.pdf>)及用户确认的现行规则（2026-10-09 补学）。**这是待实施清单，不表示任何保留工程已经修改或验证。** 应分别检查所选 BOOT 和 APP，并按对应芯片/板卡筛选适用项。新版 LIN/CAN BOOT 可用于高低压，但不能据此跳过 APP、硬件和升级协议的适配。

| 核查项 | 实施与验收点 |
|---|---|
| 时钟与 Flash | 100 MHz 目标配置下，BOOT 和 APP 的 `PAGEWAIT/RANDWAIT/OTPWAIT` 均改为 `4/4/5`；全系优先外部晶振，核对真实 PLL、ADC、PWM、LIN/CAN 时钟。旧工程中的 `3/3/5` 一律不能默认保留。 |
| PIE 向量表 | 核对向量表起点为 `0xD00`；地址 `0xD00–0xD05` 不属于中断向量，按指南跳过 3 个表项、将初始化计数 128 改为 125。检查 BOOT 和 APP 的实际初始化函数。 |
| 保留中断 | 整条执行路径放 RAM；进入后关闭中断，确保 EPWM2/3/4 的 A/B 内连引脚全低，重新使能看门狗，SCL 设输入、SDA 设 TZ，最后 `while(1)`。须在实际功率级验证关断状态。 |
| Flash API | 核对 `CPU_RATE` 与实际 CPU 主频，使用指南给出的 `ADP32F036_027_Flash_API_AUTOCLK.lib`；检查库与编译器、链接文件、RAM 执行段和擦写扇区配套，BOOT/APP 都不能只改一侧。 |
| 休眠与唤醒 | 休眠相关代码在 RAM；先封波，再拉低 `LIN_EN`，并在 3 μs 内拉低 `LIN_TXD` 且保持到 DSP 完全掉电；待 `VDDIO=0` 后再唤醒。按芯片型号及外部电路核对 VM、SCL/SDA 和 LIN 总线条件。 |
| VDDIO 下电与退耦 | V1.5 第 5 页：休眠或下电时，在芯片引脚测量 VDDIO 从 5 V 降到 2.6 V 的时间，须 >200 μs；BOOTAPP V1.1 第 8 页还要求掉电过程 VDD 在 1.08 V 以上，可通过 SCL 输入、SDA TZ、降频等减慢下电。第 6 页退耦参数按[学习表](<../../00_替代与差异知识库/18_036设计指南V1.5与BOOTAPP核查学习.md>)核查，并结合目标型号原理图；不能直接外推为 3.3 V 供电区间。 |
| SCL/SDA 与掉电 | 休眠或 VM 下降至 5.3 V 前，SCL 配输入、SDA 配 TZ；软件 I²C 读写期间才按指南切换 SCL 输出，并在停止信号后恢复输入。结合实际预驱和掉电波形确认。 |
| 在线升级可靠性 | 将新版 BOOT 与目标 APP、上位机成套校验：扇区布局、APP 入口、帧格式/CRC、完整镜像地址边界、Flash 擦写返回值和写后校验、掉电中断恢复。已发现的 LIN 越界应答和 CAN 先擦后校验头等风险须单独处理。 |

若指南项与旧工程现状矛盾，以最新版指南和用户确认的生产规则为准。后续实际修改工程时先与用户确认目标型号、板卡、BOOT/APP 组合和需要实现的升级行为，再在 CCS 编译、烧录与实板测试。
